# จัดทีมปาร์ตี้ · Ragnarok The New World

เว็บจัดทีมปาร์ตี้ (1 ปาร์ตี้ 5 คน, 1 ทีมสูงสุด 8 ปาร์ตี้) มีสำรอง หัวหน้าปาร์ตี้ ลากวาง ส่งออก JSON/Excel

- **ทุกคนเปิดดูได้โดยไม่ต้องล็อกอิน** (ดูอย่างเดียว)
- **เฉพาะผู้ดูแลที่ล็อกอินเท่านั้นที่แก้ไขได้** ข้อมูลเก็บที่ Firebase Firestore ทุกเครื่องเห็นตรงกันแบบเรียลไทม์
- โฮสต์เป็นไฟล์ static บน GitHub Pages ได้เลย ไม่ต้องมีเซิร์ฟเวอร์ ใช้ฟรีทั้งหมด

ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวโปรแกรมทั้งหมด |
| `config.js` | ค่า Firebase และอีเมลผู้ดูแล (ต้องแก้) |
| `firestore.rules` | กติกาสิทธิ์ของฐานข้อมูล (ต้องแก้อีเมล แล้วนำไปวางใน Firebase) |

---

## ลองก่อนโดยยังไม่ต้องตั้งค่าอะไร

เปิดด้วยเซิร์ฟเวอร์ในเครื่อง

```bash
cd ro-party-planner
python3 -m http.server 8000
# เปิด http://localhost:8000
```

ถ้ายังไม่ได้แก้ `config.js` จะขึ้นป้าย "💾 โหมดเครื่องเดียว" ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่แชร์ให้คนอื่น

## ตั้งค่า Firebase (ทำครั้งเดียว ประมาณ 10 นาที)

ใช้แพ็กเกจฟรี (Spark) ไม่ต้องใส่บัตรเครดิต

### 1. สร้างโปรเจกต์
1. เข้า <https://console.firebase.google.com> ล็อกอินด้วยบัญชี Google (ใช้บัญชีส่วนตัวหรือบริษัทก็ได้)
2. **Add project** ตั้งชื่อ เช่น `ro-party-planner` ปิด Google Analytics ได้

### 2. เปิด Firestore
1. เมนูซ้าย **Build → Firestore Database → Create database**
2. เลือกโหมด **Production mode** และ location ใกล้ไทย เช่น `asia-southeast1` (Singapore)

### 3. ใส่กติกาสิทธิ์
1. แท็บ **Rules** ในหน้า Firestore
2. เปิดไฟล์ `firestore.rules` **แก้อีเมล `admin@example.com` เป็นอีเมลผู้ดูแลจริง**
3. คัดลอกทั้งไฟล์ไปวางแทนของเดิม แล้วกด **Publish**

### 4. เปิดการล็อกอินด้วยอีเมลและสร้างบัญชีผู้ดูแล
1. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**
2. แท็บ **Users → Add user** ใส่อีเมลและรหัสผ่านของผู้ดูแล (อีเมลนี้ต้องตรงกับใน `firestore.rules`)
3. ถ้ามีตัวเลือกใน Settings → User actions แนะนำให้ปิด "Enable create (sign-up)" เพื่อไม่ให้คนอื่นสมัครเอง
   (แม้ไม่ปิด คนอื่นก็เขียนข้อมูลไม่ได้ เพราะ rules อนุญาตเฉพาะอีเมลผู้ดูแล)

### 5. ใส่ค่า config ในเว็บ
1. **Project settings (ไอคอนเฟือง) → Your apps → ไอคอน Web `</>`** ตั้งชื่อแอป แล้วกด Register (ไม่ต้องเปิด Hosting)
2. คัดลอกค่า `apiKey`, `authDomain`, `projectId`, `appId` ไปใส่ใน `config.js`
3. แก้ `adminEmails` ให้เป็นอีเมลผู้ดูแล

> ค่า `apiKey` ของ Firebase เว็บไม่ใช่ความลับ ใส่ใน GitHub ได้ ส่วนที่กันคนอื่นแก้ข้อมูลคือ `firestore.rules`
> **อย่าใส่รหัสผ่านลงในไฟล์ใดๆ ในโปรเจกต์**

## Deploy บน GitHub Pages

```bash
cd ro-party-planner
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

จากนั้นบน GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ส่งให้ทุกคนได้เลย

- แพ็กเกจ GitHub ฟรีใช้ Pages ได้กับ **repo แบบ Public** เท่านั้น (repo ส่วนตัวต้องใช้แพ็กเกจเสียเงินหรือโฮสต์ที่อื่น เช่น Cloudflare Pages / Netlify ซึ่งใช้ไฟล์ชุดเดียวกันได้)
- ถ้าล็อกอินไม่ได้หลัง deploy ให้ดูที่ **Authentication → Settings → Authorized domains** และเพิ่ม `<ชื่อผู้ใช้>.github.io`

## ย้ายข้อมูลเดิมจากหน้าเวอร์ชัน claude.ai

1. เปิดหน้าเดิมด้วยบัญชีเจ้าของ กดปุ่ม **ส่งออก/นำเข้า → ดาวน์โหลด JSON** (หรือ "คัดลอก JSON")
2. เปิดเว็บใหม่ กด **เข้าสู่ระบบผู้ดูแล**
3. กด **ส่งออก/นำเข้า → นำเข้า** เลือกไฟล์ JSON (หรือวางข้อความ) ข้อมูลจะถูกเพิ่มเข้าไป ไม่ลบของเดิม

(ถ้าเปิดเว็บใหม่บนเบราว์เซอร์เดียวกับที่เคยใช้ข้อมูลเก่า และยังเป็นการล็อกอินผู้ดูแลครั้งแรก ระบบจะถามให้รวมข้อมูลเก่าในเครื่องให้เองหนึ่งครั้ง)

## วิธีใช้งาน

- **ผู้ชม:** เปิดลิงก์ ดูทีม สลับแท็บ คัดลอกรายชื่อ ดาวน์โหลด JSON/Excel
- **ผู้ดูแล:** กด "เข้าสู่ระบบผู้ดูแล" มุมขวาบน ใส่อีเมลและรหัสผ่าน จะแก้ไขได้ทุกอย่าง บันทึกอัตโนมัติ คนที่เปิดหน้าอยู่เห็นการเปลี่ยนแปลงทันที
- ข้อมูลทั้งหมดอยู่ใน Firestore เอกสาร `planner/state` (และ `planner/icons` สำหรับไอคอนอาชีพ) สำรองข้อมูลได้จากปุ่มส่งออก JSON

## หมายเหตุ

- ถ้าผู้ดูแลสองคนแก้พร้อมกัน การบันทึกล่าสุดจะทับ (ไม่มีการล็อกทีละคน)
- โควตาฟรีของ Firestore เพียงพอสำหรับกิลด์ทั่วไปมาก (อ่าน 50,000 ครั้ง/วัน) ผู้ชมแต่ละคนใช้ประมาณ 2 ครั้งต่อการเปิดหน้า
- เปลี่ยนรายชื่ออาชีพ สี ไอคอน และกิจกรรมได้ในหน้าเว็บ (เฉพาะผู้ดูแล) ไม่ต้องแก้โค้ด
